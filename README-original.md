# WayMuse · 大学生活工作台

0.11.0 · 可操作演示版。基于现有 React / TypeScript / Vite 项目改进。

## 使用

首次进入可点击「先体验演示工作台」，也可完成本地档案引导。演示附带三项任务和三条背景记忆，均可自由修改。

- 今天：按优先级、截止日期选出下一步行动，直接完成任务，查看今日课程。
- 任务：新增、编辑、日期、优先级、分类、搜索、状态筛选、完成与恢复、删除撤销。
- 课程：从「添加课程」查看每周课程；支持新增、编辑和删除撤销。首页只展示上海时区当天课程。
- 记忆：新增、点击内容编辑、删除撤销。
- 对话：连接自己的 DeepSeek 密钥后使用真实 API；未配置时显示连接引导。设置可导出本地资料。

资料保存在当前浏览器，不同设备与站点域名之间不自动同步。文件入口只保存文件名和备注，不提供 OCR、音频转写或文件持久化。没有后台定时提醒或系统使用时长读取。

## 开发

Node.js 22 或更新版本，执行 `npm ci`、`npm run dev`。

检查：`npm run typecheck`、`npm run format:check`、`npm run build`。

桌面 900px 以上使用侧栏与双栏首页；手机使用单列与底部导航。支持系统深色模式和减少动画偏好。

验收记录见 `docs/reports/0.11.0-demo.md`。原有许可与第三方声明继续有效。
