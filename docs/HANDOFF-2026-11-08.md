## 3. 这一轮做了什么

### 3.1 iOS 原生外壳

| 能力 | 实现 | 位置 |
| --- | --- | --- |
| 原生 Liquid Glass Tab 栏 | 启用被写死为 `false` 的 `useNativeTabs`；**不绑 DOM**，贴底自由布局，用 `getTabBarLayout()` 拿真实高度写入 CSS 变量 `--native-tabbar` | `src/useNativeTabs.ts` |
| Dock 跟随原生栏 | Dock 抬到 `var(--native-tabbar) + 8px`，网页 Tab 行 `display:none`，内容区/聊天区底部留白同步 | `src/styles/layout.css`、`tokens.css` |
| 原生聊天输入框 | 新增 `NativeComposePlugin` + `NativeComposeOverlay`（UITextField + 附件/发送键 + 键盘避让，iOS 26 用 `UIGlassEffect`） | `patches/liquid-glass/*.swift` |
| 注入机制 | `postinstall` 把 Swift 复制进已链接的 SPM target；`cap sync` 之后再把类名写进 `packageClassList` | `scripts/inject-native-compose.cjs`、`scripts/register-native-compose.cjs` |
| Web 侧接线 | `useNativeCompose()`：量 DOM 矩形 → 同步给原生；文本双向同步防回写循环；原生激活时网页输入框 `opacity:0` | `src/nativeCompose.ts`、`src/pages/Dock.tsx` |

**为什么不能直接改 node_modules / pbxproj**：前者被 `npm ci` 覆盖，后者要改 4 处引用容易写坏工程。详见 `docs/NATIVE-COMPOSE.md`。

### 3.2 闭环（这是产品上最关键的部分）

| 环节 | 现状 |
| --- | --- |
| 对话 → 方案卡 | `<plans>` 契约块，支持 `deadline` / `priority` |
| 对话 → 记忆卡 | **新增** `<memories>` 契约块，确认后写入记忆（此前只能手输） |
| 无 API Key | **新增** `localSuggestions()` 本地兜底，5 类场景，仍能走完整闭环 |
| Today | **新增**「今天到期」区块，按 deadline 排序，逾期高亮 |

实测（浏览器，无 Key）：

```text
输入「明天考试，我有点慌」
→ 回复 + 方案卡「今晚 90 分钟复习」(3 步) + 记忆卡「近期有考试，容易焦虑」
→ 采纳方案 → 3 条任务写入，deadline=次日，priority=high
→ 采纳记忆 → 记忆写入
```

### 3.3 头像

- 造型：**深色圆球（`#17191c`）+ 只有两只眼睛**，没有眉毛 / 腮红 / 嘴
  （用户明确要求：眼睛比参考图更大，情绪靠眼神传，不要五官）
- 眼神动效（纯 CSS）：
  - 呼吸 5s（scale 1→1.028）
  - **双眨** 5.6s 一次：闭 → 开 → 半闭 → 开，不是匀速缩放
  - 注视漂移 9s 一轮：左看 → 回中 → 右看，带 ±1.5° 歪头
  - **回复中**：呼吸 2.6s、注视切换 3.2s，并持续眯眼（scaleY 0.6）= 专注感
- 遵守 `prefers-reduced-motion`（全部静止）
- 位置：`src/BotAvatar.tsx`、`src/styles/chat.css`、`public/avatar.svg`（同步）

### 3.4 CI

`.github/workflows/ios-build.yml` 现在的步骤顺序**不能随意调整**：

```text
npm ci                    ← 触发 postinstall，注入 Swift 到 node_modules
typecheck / lint / build
npx cap sync ios          ← 会重写 ios/App/App/capacitor.config.json
node scripts/register-native-compose.cjs   ← 必须在 sync 之后
xcodebuild -resolvePackageDependencies     ← 8 次递增退避重试（GitHub CDN 会 504）
actions/cache/save        ← 解析成功立刻存盘，后续编译失败也不浪费
xcodebuild build          ← 产出 unsigned IPA
package + upload artifact
```

## 5. 还没做（按优先级）

### P1 —— 决定「能不能留住用户」

1. **本地通知**：上课前 10 分钟 / 截止前一天 20:00 / 每日一句。用 `UNUserNotificationCenter`，不需要服务端。
2. **课表导入**：至少支持 `.ics` / CSV；OCR 需要后端，可后置。
3. **数据备份**：现在卸载即丢。至少导出/导入 + iCloud 文档。
4. **任务编辑**：现在只能勾选和删除，不能改文本/日期/优先级。

### P2 —— 决定「能不能上线」

5. **后端代理**：Key 不能留在客户端直连 `api.deepseek.com`，需要代理 + 限流 + 内容安全。
6. **隐私合规**：隐私文案要匹配真实数据流；`docs/PRIVACY.md` 需要复核。
7. **崩溃上报/埋点**：目前完全没有，只能靠用户抱怨。

### 技术债

8. `postinstall` 往 `node_modules` 注入 Swift 是妥协方案。长期建议：**fork 插件成独立 repo，用 `file:` 依赖**，上游更新时冲突可见。
9. 无测试、无 CI 上的 Web 单测。
10. `main` 落后于 `feat/native-compose`，确认后应合并。

## 8. 排错手册（都踩过）

| 症状 | 根因 | 处理 |
| --- | --- | --- |
| CI 55 秒失败，exit 74 | SPM 拉 `Capacitor.xcframework.zip` 返回 504 | 已有 8 次递增退避重试 + 缓存；偶发仍可重跑 |
| `cannot find 'NativeComposePlugin' in scope` | App target 看不见 SPM 模块里的类 | 不要 import；改用 `packageClassList` 字符串注册 |
| 输入框还是网页样式（无报错） | `postinstall` 没注入，或 `package.json` 的 postinstall 丢了 | 查 `node_modules/@ajuarezso/capacitor-liquid-glass/ios/Sources/LiquidGlassPlugin/` 有没有那两个 Swift |
| Tab 栏被压扁、文字被裁 | 把原生 UITabBar 绑进了 56px 的 DOM 槽位 | 已修：不传 `containerElement`，用真实高度做 CSS 变量 |
| 原生栏盖住输入框 | 早期 bottom-pinned + 未预留空间 | 已修：Dock 用 `--native-tabbar` 上移 |
| 键盘弹出时输入框被顶到屏幕中部 | 双重抬升：WebKit 因视口变化已让位，原生又减了一次键盘高度 | 已修（`df4d9fb`）：改成「最小必要抬升」，只在会遮挡时上移到键盘上方 8px |
| 构建产物里 `packageClassList` 少了插件 | `register-native-compose.cjs` 在 `cap sync` 之前跑了 | 顺序：sync → register → build |

## 9. 用户此前明确过的规则（别违反）

1. **不假装已接通**：没接通的入口一律不显示（此前删过「连接应用 / 技能 / 灵感」）。
2. **能力要真实**：演示数据必须标明是本地/模拟，不能暗示云端同步或系统级权限。
3. **分阶段交付**：每阶段结束列文件、命令、实测结果、手动检查清单，然后停下等确认。
4. **数据最小化**：「记忆」要可查看、可逐条删除、可关闭。
5. **不要为了好看牺牲可读性**：对比度、触控目标 44px、reduced-motion。
6. **不加无谓功能**：不要加第 6 个 Tab、社区、复杂动效体系。
