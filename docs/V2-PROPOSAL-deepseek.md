# DeepSeek 的 V2.0 判断（2026-11-16）

> 回应 chez：「你们可以思考，当下大学生真正需要的是什么」「也许有些功能一开始我做的就是错的」。

## 一、先说结论

**这个 App 现在最像"功能很多的课表工具"，最该变成"每天只逼你做对一件事的搭子"。**

学生不缺工具：课表有超级课程表，待办有滴答清单，笔记有 Notion。他们缺的是**有人替他把"今天到底该干什么"想清楚，并且在他不想干的时候陪他迈出第一步**。

所以 V2.0 的取舍标准只有一条：**这个功能能不能让人今天多完成一件事？** 不能的，砍掉或往后放。

## 二、学生真实的四个痛点（按强度排序）

### 1. 决策疲劳，不是任务缺失
课表、作业、社团、实习、考研信息全在脑子里打架，打开 App 看到 12 个任务，第一反应是关掉。
**要的不是列表，是"现在做这一件"。**

### 2. 启动困难，不是不会做
"知道该复习"和"坐下开始复习"之间隔着一条河。番茄钟要求人先有意志力，而人恰恰没有。
**要的是被推一把：一句话、一个动作、两分钟就能开始。**

### 3. 情绪无处可说
跟同学说怕被比较，跟父母说怕被担心，跟咨询师说排不上队。
**要的是一个不会评价他、也不会泄密的耳朵。**

### 4. 重复劳动
每学期录课表、每门课记作业、每次考试重新排计划——全是手工活。
**要的是"拍一张、说一句就完事"。**

## 三、如果只能做五件事（我的优先级）

| # | 能力 | 为什么排这里 | 现在离目标差多远 |
| --- | --- | --- | --- |
| 1 | **今日三件**：从课表/作业/记忆里自动算出"今天最该做的三件"，并给第一步动作 | 直接打痛点 1、2；也是唯一每天会被打开的理由 | 已有雏形（Today + 简报卡），但还没有"第一步动作"和"做完打勾"的闭环 |
| 2 | **零录入**：课表截图识别、作业一句话录入、教务系统粘贴 | 决定新用户能不能活过第一天 | 截图识别已可用；作业录入仍靠手打 |
| 3 | **语音陪伴**：走路/睡前能聊，能被打断，能记住说过什么 | 唯一能形成情感依赖的入口，也是和竞品拉开差距的地方 | TTS 已通；**ASR 还是坏的**（真机 partial 全空） |
| 4 | **记忆可查可改可删**：它记住了什么，用户能看见、能纠正 | 陪伴类产品的信任底线；也直接对应合规 | 大脑图有了，但"我记错了"没有修正入口 |
| 5 | **跨设备与备份**：换手机不丢、能导出 | 决定用户敢不敢长期用 | 本机备份/恢复有；跨设备同步没有 |

## 四、我认为现在做错或该砍的

| 项 | 判断 | 建议 |
| --- | --- | --- |
| 健康卡（睡眠/步数/心率） | **假数据**（`src/health.ts` 固定值 7h20 / 8432 / 62），会让人以为是真的 | 立刻下线，或明确标注"示例"；真数据要等 iOS 付费账号 + Android Health Connect |
| 屏幕时间/步数 | 数据本身有价值，但采集成本高、解释成本更高 | 保留 Android，但不进主界面，只在对话里被问到才用 |
| 多会话、长文档导出 | 是"重度用户"需求，不是"活下来"需求 | V2.1 再做 |
| 表情包 / 花哨动画 | 增加的是"有趣"，不是"完成" | 暂缓（chez 已决定先放） |
| 通话浮窗 | 方向对（语音陪伴），但现在没有 ASR 就是空壳 | 先把 ASR 修好，浮窗才有意义 |

## 五、V2.0 我建议的范围（可验收）

```
阶段一（2 周）：可信
  - ASR 真机打通（iOS 先通，Android 插件补齐）
  - 下线/标注假数据
  - 今日三件闭环：自动生成 → 一键开始 → 完成回写 → 明日调整
  - 记忆纠正入口（改 / 删 / "这条不对"）

阶段二（3 周）：可迁移
  - 账号体系下的跨设备同步（课表、任务、记忆、聊天摘要）
  - 导出与删除（合规底线）

阶段三（3 周）：可依赖
  - 语音陪伴（打断、记住、主动开口的边界）
  - 每周复盘自动生成，且能解释"为什么这么排"
```

每一条的验收都用**可核证据**：提交哈希 + 自动测试 + 双端实测记录 + 回滚方式。

## 六、一个反向问题

如果只能保留一个功能让学生明天还打开它，我选 **今日三件**。
如果连这个都做不扎实，加多少功能都没用。
