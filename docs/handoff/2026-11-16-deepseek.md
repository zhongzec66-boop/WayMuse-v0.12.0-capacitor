## 六、今天新增的需求（还没做）

chez 通过 Codex 转达的课表新需求：

1. 课表要**能放大看细节**（缩放 / 全屏，可恢复默认；星期与时间标尺保持定位）。
2. 课程**颜色**、**重点标记**（文字或星标）、**备注**。
3. 点开课程可**编辑详情**。
4. **重新导入课表时保留用户设置的颜色与备注**。

技术要点（我判断，待 Codex 定）：

- `Course` 需要扩字段：`color?`、`starred?`、`note?`（旧数据缺省不影响）。
- 重导入的合并键不能只用 `name|weekday|start|weeks`——颜色备注属于"用户覆盖层"，建议导入时按同一键**合并用户字段**而不是覆盖整条。
- 缩放/全屏是纯视图状态，不进数据。
