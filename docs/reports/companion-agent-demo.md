# 陪伴学习 Agent 演示

- 保留 TodayAI 参考的悬浮顶栏与底部玻璃导航。
- 未配置模型时为明确标注的本地示例，按短段依次展示；真实模式使用流式模型回复，提示词要求短句分段。
- 模型可返回 `<plans>` JSON 方案协议；验证后渲染最多三个方案。建议不会自动执行。
- 用户确认后，方案步骤进入共用任务存储，Today、计划和后续聊天可读取同一状态。支持撤回、勾选、删除；通过稳定任务 ID 防重复加入。
- 左上角进入完整设置。档案、名字、头像和陪伴设置自动保存，模型配置需保存。返回聊天后重新加载模型配置。
- App 连接仅为预览。可明确点选将模拟健康/日历/学习资料写入本机记忆；不读取真实设备或外部服务。

## 手机小范围测试

建议先验证：聊天短段 → 选方案 → 计划查看/勾选 → 返回聊天询问进度 → 刷新保留 → 撤回；再验证设置改名和连接样例导入。
当前数据保存在同一浏览器本机，无账号隔离、跨设备同步或服务器数据副本。真实模型请求在浏览器发起，发送聊天和用户开启的上下文；不要把 API Key 写入构建或分享的测试页面。

## 后续自有服务器

本轮尚未部署到自有服务器。项目是 Vite 静态站，可 `npm ci && npm run build`，将 `dist/` 放到 HTTPS 静态服务。正式多人测试前应增加后端模型代理、账号隔离及密钥管理。迁移到新域名不会自动搬迁原浏览器数据。

## 验证范围

构建及方案解析、结构校验、稳定 ID、共享任务状态检查；浏览器验证选方案、跨页面读取、设置入口。真实模型端到端与 iPhone Safari 真机未验证。
