# WayMuse 视觉验收清单（草稿，待 Denise 定目录后由 DeepSeek 原样提交到仓库）

- 用途：Doubao 每版跑截图矩阵 + 像素 diff，对照本清单判定每屏过/不过；我拿 Doubao 的首份视觉报告对照人工审过的双包挑刺清单验收。
- 依据：`WayMuse-双包挑刺清单.md`（2026-11-12 源码复核版）里已确认的排布与视觉问题。
- 分工：DeepSeek 给状态清单和种子数据（课表、作业、考试、记忆），每次出包给最新 iOS IPA + Android APK；Doubao 搭环境、跑矩阵、只报「哪一屏、哪个状态、差在哪」，不判断好坏；我出本清单并验收报告。

## 三、iOS / Android 分包必查

- iOS：相机/相册权限声明已补（否则课表图片导入死在最后一步）；语音朗读按钮可点且真机出声；提醒后台能力（UIBackgroundModes）状态如实记录。
- Android：后端为正式域名（设置页不得出现 sslip/裸 IP）；主题绿 + 行高 1.55；RECORD_AUDIO 权限与语音输入接线；作业 48/12/2 小时提醒触发逻辑存在；权限清单无 DUMP、无已淘汰的 READ_EXTERNAL_STORAGE。

## 四、Doubao 报告格式（每版一份）

每处差异一行：`[包 iOS/Android + 版本] 屏幕 / 状态 / 差在哪 / 截图路径`，并附 diff 图。只报事实，不判断好坏；与上一版的回归对比单独列一节（改了 A、 B 有没有塌）。

## 五、环境前提（待 Doubao 回复）

- 有 Android 模拟器 → 全自动截图；只有 Windows → Web 模式（headless Chrome 全套，但验不了原生 Tab 栏、原生输入框、安全区）；iOS 在 Windows 只能真机人工点、程序收集截图。
