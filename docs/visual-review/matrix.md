# 截图矩阵（机器可读版）

配合 `视觉验收清单-草稿.md`（判定标准）与 `seed.json`（数据）使用。
每行 = 一个可截图的界面状态。`id` 用于报告里的定位。

## 约定

- 屏幕宽度 390pt（iPhone 14 / 常见安卓 1080p@3x），高度 844pt。
- 语言中文，浅色模式；暗色单独一轮。
- Web 模式：headless Chrome 加载 `dist/`，先写入种子与演示态再截图。
- 每张图命名：`<包>-<版本>-<id>.png`。

## 聊天页（chat）

| id | 状态 | 进入方式 | 期望 |
| --- | --- | --- | --- |
| chat-empty | 空会话 | 清空消息 | 6 条以内建议条 + 「直接说事，或者从下面挑一个」，不压输入框 |
| chat-reply | 普通回复 | 发「今天适合做什么」 | 助手白气泡 + 细边框；用户气泡绿色、宽 ≤78% |
| chat-streaming | 流式输出中 | 发送后立即截图 | 有占位/光标，不跳动 |
| chat-code | 长代码回复 | 发「写个快排」 | 代码卡、可复制、不溢出 |
| chat-cards | 方案卡/作业确认卡 | 触发计划或作业提议 | 卡片不超出气泡，按钮可点 |
| chat-kb | 命中经验库 | 发「保研怎么准备」 | 引用条 + 可展开，不遮挡字幕 |
| chat-image | 图片消息 | 发送截图 | 缩略图圆角，不拉伸 |
| chat-error | 断网报错 | 断网后发送 | 只给下一步动作，无技术名词（G7） |

## 朗读与语音

| id | 状态 | 进入方式 | 期望 |
| --- | --- | --- | --- |
| voice-idle | 默认 | 打开一条回复 | 按钮显示「朗读」，无耗时数字 |
| voice-playing | 播放中 | 点朗读 | 只有该条显示「停止」，其余仍「朗读」 |
| voice-error | 合成失败 | 断网后点朗读 | 一行灰字「语音没读出来，先看文字」 |
