WayMuse 是一款面向大学生的本地学习规划演示应用。我们尽量少收集数据，并把当前版本的能力边界写清楚。

## 1. 当前版本保存哪些数据

在当前版本中，以下内容只保存在你的设备本地（浏览器存储 / App 沙盒），不会上传到我们的服务器：

- 你填写的称呼、WayMuse 头像；
- 学校、专业、年级、主要课程；
- 你手动添加的课程（名称、星期、时间、地点）；
- 你添加的任务与完成状态；
- 你添加的记忆条目；
- 你是否完成首次进入流程。

WayMuse 头像由你主动选择，浏览器会裁成 256px JPEG 后保存；不会上传到我们的服务器。

## 2. 文件、图片与录音

- 你选择的文档、图片、音频只在当前页面预览；
- 保存资料时，应用只记录文件名和你的备注，不保存文件内容；
- 当前版本不做 OCR、语音转写或课表识别；
- 录音需要麦克风权限，录音内容不会上传，也不会在关闭页面后保留；
- 选择图片/文件需要相册或文件访问权限，仅用于你主动选择的内容。

## 3. 可选的 DeepSeek 真实接入

聊天页有一个可选的 DeepSeek 接入。只有你在聊天页或“设置 → AI 连接”中填写自己的 DeepSeek API Key 并发送消息时，才会发生以下行为：

- 你输入的对话内容会发送到 `api.deepseek.com`；
- 如果你开启“带入本地演示数据”，称呼、学业档案、记忆、课程和任务会作为上下文一并发送；
- API Key 默认只保存在本次会话的会话存储中；勾选“记住密钥”后会写入本机 localStorage；
- 该页面不会把数据发送到 DeepSeek 之外的地址，也不使用你的数据训练模型（具体以 DeepSeek 的隐私政策为准）。

不使用这个接入时，聊天页不会发起任何 AI 请求。

## 4. 当前版本没有做什么

- 没有账户系统，没有登录，也没有云端同步；
- 没有默认开启的 AI 调用；
- 没有读取你的学校账户、日历、通讯录或位置；
- 没有广告 SDK、分析 SDK 或跨 App 追踪；
- “手动添加资料”中的服务均标注为“规划中”，不会发起真实授权。

## 5. 数据共享

当前版本不向第三方出售、出租或共享你的个人数据。只有你在聊天页主动发送消息时，相关对话与上下文才会发送给 DeepSeek。应用运行所需的资源由本地打包提供；如果你通过 App Store 安装，Apple 可能按其隐私政策处理崩溃日志、购买等信息。

## 6. 你的控制

- 你可以在设置中单独删除课程和记忆；
- 你可以在聊天页的连接设置中清除密钥、配置和本地对话；
- 你可以使用“清除全部演示数据”一次性删除本机数据并回到首次进入；
- 卸载 App 或清除浏览器数据也会删除本地内容；
- 当前没有账户，因此没有需要注销的云端账户。

## 7. 儿童与未成年人

WayMuse 面向大学生。当前版本不主动收集年龄、学校或身份信息。若未来接入账户或正式 AI 对话，我们会重新评估年龄分级与监护人同意要求。

## 8. 安全

本地数据保存在 App 沙盒或浏览器存储中。我们不会通过不安全的通道传输数据。聊天页的 DeepSeek 接入通过 HTTPS 把你主动发送的对话与上下文直接发往 `api.deepseek.com`；应用本身没有账户数据或云端存储。请注意，任何设备上的本地数据都可能被设备备份、越狱工具或共享设备的使用者访问。

## 9. 变更

如果未来接入账户、云端同步、正式 AI 服务、课表导入或日历，我们会在上线前更新本政策，并在读取新数据前重新征求你的授权。重大变更会在 App 内提示。
