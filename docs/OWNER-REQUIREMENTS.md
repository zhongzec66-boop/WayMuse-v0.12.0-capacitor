## 四、需要讨论的四个问题

1. **首包必须有哪几条？** 我建议：聊天（服务端）+ 课表导入 + 今日三件 + 记忆查看/删除 + 账号注销 + 隐私政策。语音若 ASR 仍不通，是否首包先不带？
2. **语音的取舍**：ASR 真机仍未通（iOS partial 全空），TTS 已可用。首包是「只有朗读」还是等 ASR 通了再一起上？
3. **免费/开源与代传账号**：朋友的个人账号上架，长期要开源的话，有没有冲突（法律/账号归属）？要不要在内测阶段就写清归属协议？
4. **学生真实需求**：请 Denise 与 Codex 各给「学生最需要的三件事」，与我的五条（今日三件、零录入、语音陪伴、记忆可控、跨设备）对照，取并集定 V2 范围。
